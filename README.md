# 论文与实验报告格式自检排版器

纯本地运行，不上传服务器，双击即用，Windows/Mac 通用，单文件离线 HTML5 工具。

爱发电主页：<https://ifdian.net/a/naiwatools>（3 个工具 9.9 元一次性单品）

## 功能

- **精确字数统计**：粘贴文本或导入文档，一键统计精确字数、字符数、段落数。
- **一键清洗格式**：自动清除多余空行，统一全角半角、乱码标点。
- **自动生成标准目录层级**：根据标题层级自动生成规范目录结构。
- **参考文献格式预览**：按常见规范生成预览，方便对照修改。

## 离线使用

1. 获取工具文件。
2. 解压 ZIP，得到《论文与实验报告格式自检排版器.html》。
3. 双击用 Chrome/Edge/Firefox/Safari 打开。
4. 粘贴文本或导入文档，点统计字数看结果，点一键清洗清格式，再按生成的目录层级和参考文献预览对照修改正文。

不需要联网，不需要注册，不需要安装。

## 隐私

所有处理均在本地浏览器完成，论文、实验数据不上传到任何服务器，断网也能用。

## 适用

- 毕业论文、课程论文、实验报告交稿前格式自检。
- 检查字数、清理空行乱标点、核对目录参考文献。
